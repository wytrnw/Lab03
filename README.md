1.Разницы в результате нету, отличие только в том, что код короче и читается быстрее

2.x++ (постфикс) сначала отдаёт старое значение, а потом уже увеличивает переменную. ++x (префикс) наоборот, сначала увеличивает, а потом отдаёт новое значение.

3.Всегда получается bool, то есть true или false.

4.Короткое замыкание, это когда C# прекращает проверять остальные условия, потому что результат уже ясен. В &&, если первое условие false, второе даже не проверяется, ведь всё равно будет false. В ||, если первое true, второе не проверяется, результат уже является true. Пример: допустим, нужно проверить, можно ли делить на число. Пишу b != 0 && a / b > 2. Если b равно нулю, то b != 0 даст false, и деление a / b даже не выполнится, но ошибку не выдаст. Без короткого замыкания программа попыталась бы поделить на ноль и выдала ошибку.
